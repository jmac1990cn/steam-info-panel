Steam 游戏速查面板

版本 1.0.9 · 打开任意 Steam 商店游戏页，右侧自动显示六项检测结果

六项功能

  • 史低价格：ITAD（可选 key）取 Steam 国区史低 + Steam 国区/美区当前价，兜底 CheapShark 美元口径
  • 家庭库是否已有：读取账号 userdata 与页面库存提示，区分本人拥有 / 家庭共享
  • DLC 是否单独下载：拉取 DLC 清单，按类型区分「随本体安装」与「独立下载项」
  • 是否在 XGP 会员库：比对 Xbox Game Pass 目录
  • 是否有 D 加密：来自 PCGamingWiki / SteamDB 的 Denuvo 与 DRM 信息
  • 是否在 Epic 免费过：比对 Epic 历史免费记录（ITAD 赠送记录）

ITAD API key（国区史低 + Epic 免费检测共用）

插件不再内置 key，需自行免费申请：登录 IsThereAnyDeal 后进入 My Apps（isthereanydeal.com/apps/my） 创建应用即可生成 key（API 文档：docs.isthereanydeal.com）。
配置后可得到 Steam 商店国区精确史低，并启用「Epic 免费检测」；不配置时国区史低退化为本地观测口径，Epic 检测不可用。

Epic 免费检测（显示「是否在 Epic 免费过」）

免登录比对 Epic 历史免费记录：当前游戏若在 Epic 曾 / 正 / 将 0 元领取， Steam 商店页面板会提示。数据源为 IsThereAnyDeal 赠送记录（需在上方「ITAD API key」处配置自己的 key， 点此申请）， 覆盖 Epic 自 2018 年起每周喜加一历史。

Steam 客户端本地数据

导入后可离线判定「本人拥有」与「家庭共享借入」，无需网页登录态。

使用提示

  • 「家庭库是否已有」需要浏览器已登录 Steam 商店；未登录时该项显示「未登录」。
  • XGP 目录接口依赖网络可达性，若显示「待确认」，请点击该项在 Xbox 官网手动核对。
  • 面板点击标题可折叠，点击任意一行展开详情，点「重新检测」强制刷新全部数据。
  • 在 Steam 客户端（Millennium / Extendium）里请勿点击「扩展程序选项」——该环境（CEF）没有浏览器标签页， 打开设置页会导致客户端闪退。请直接使用商店页面板上的「⚙ 设置」，功能与本页一致。
